## 字体与费用来源

字体随网站提供，不依赖用户访问外部字体服务。`web/public/fonts/` 包含 101 个 Unicode 子集 WOFF2，合计 4,516,508 字节，浏览器按需下载；本次首页测试实际请求 15 个子集。目录内保留 SIL OFL 1.1 许可证、来源 URL 与哈希记录。

后台新增 `web_api/usage.py` 只读投影，使用持久化任务 turn_id 过滤已有账本。先验证 owner，再按单次/对话统计；不修改模型计费、预算停止或核心工具逻辑。live health 只暴露预算是否停止，不再暴露全局金额。管理者仍需在后端查全局账本，此次没有新增管理员网页。

费用截图读取以前真实 DeepSeek 测试留下的一个三问题对话：10 次请求，输入 216204、输出 1867、缓存命中 164864 token，预计成本 0.12421056 元。读取前后账本字节完全相同；浏览器禁止 API 写请求，验证服务使用占位密钥，没有新增真实模型请求。金额按原有本地保守单价估算，不是服务商账单，也不是向查看者收款。

## 启动与下一步

在项目根目录运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-web.ps1`，打开 http://127.0.0.1:8765/ 。根据随后用户的明确要求，正常启动现已默认使用 DeepSeek，自动读取已有 `.env`；本地测试必须显式传 `-Mode offline`。启动和停止需使用相同模式，两种模式的数据与账本分开保存。上方改版验证时的本地模式记录为历史测试事实，不代表当前日常默认配置。
