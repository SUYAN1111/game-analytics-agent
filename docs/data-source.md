# 自选数据与中文产品界面

网页品牌为“玩家洞察”，采用自绘 SVG 对话与数据图标。五个入口为版本对比、参与预测、玩家分组、玩法关联、指标说明。页面去除离线联调及故障测试入口，后台测试机制和全部原工具仍保留。新中文示例通过别名映射到原离线场景，原问题也继续可用。分类只展开说明，不覆盖输入；示例填入前保护已有草稿，点击发送才执行；示例模式不宣称支持任意自由提问。

## 当前支持

- 选择任意列结构的 CSV / `.xlsx` 文件，或包含它们的文件夹；不会扫描未选择的路径。
- 文件在独立浏览器 Worker 内解析，不上传，不提交给模型。CSV 支持引号、逗号内嵌、换行、BOM，UTF-8 和 GB18030 编码。CSV 不自动转换数字，保留 `001` 等编号。
- Excel 支持多个工作表；数值保留读入的数字字符串，日期显示 ISO。只读取单元格值，不执行公式、宏、HTML、链接或外部连接；公式依赖工作簿已有的缓存值，不在浏览器重新计算。预览不是 Excel 的完整格式渲染。
- 选择第一行是否为列名，查看行列数和前八行。无列名/重复列名按列序号区分；列数不一致提示检查。
- 手动将列对应到玩家编号、发生时间、玩法/行为名称、版本、剧情编号和时长。所有字段可留空；至少选择一个字段才能保存，同一列不可重复对应。
- 配置按文件内容 SHA-256、工作表、首行设置和编码绑定。只保存列对应关系到 localStorage；重选同一文件恢复。下载的 JSON 含名称、指纹、列名和配置，不含数据行，状态为 `draft_not_connected`。
- 默认分析数据仍是已核验的固定模拟数据。预览、保存、下载都不会切换当前数据，也不会执行分析。

## 限制与反馈

单文件 5 MB，一次 10 个表格、共 20 MB；单表 20,000 数据行、100 列、250,000 单元格；工作簿最多 20 张工作表。Excel 压缩目录在展开前检查，声明的解压大小最多 32 MB；解析 Worker 20 秒超时后终止。对空表、损坏的 CSV/工作簿、旧 `.xls`、编码和大小问题给出中文提示。大规模数据接入应采用服务器端受控导入，不能把浏览器预览当作全量数据处理管线。

选择新的一批文件会替换当前预览列表，原分析结果不受影响。浏览器刷新后需要重新选择原文件，文件内容不会自动恢复。文件夹中不支持的文件会跳过并提示。文件选择器的文件夹权限由浏览器按用户操作确认。

## 真正切换分析数据前还需完成

当前 `APP_ASSET_DIR` 只支持定位与发布清单一致的完整资产包，不能用于任意业务表。后续需增加独立数据源登记、字段类型/时间单位/去重/采集完整性校验、现有十工具的数据适配，以及预测和分组模型的兼容性检查。新建对话绑定数据源版本，历史回答保留原数据身份；只有通过对应能力的检查后，才能开放“用于分析”。本次不新增训练、挖掘或绕过发布校验。

解析依赖锁定在 `web/package-lock.json`。Excel 使用 [read-excel-file 官方项目](https://github.com/catamphetamine/read-excel-file) 的 universal 入口，由项目自己的 Worker 管理超时；CSV 使用 Papa Parse。所有解析代码由本地生产构建提供，不运行远程脚本。

```powershell
.\.venv-core\Scripts\python.exe -B -m product_core verify

node web/browser-refinement.mjs
```
